# Introducción

**Bosque Antiguo App** es la adaptación móvil del proyecto web original *Bosque Antiguo*, desarrollada con **Kotlin** y **Jetpack Compose** como parte del curso *Desarrollo de Aplicaciones Móviles (DSY1105)*.

Esta versión traslada la esencia de la tienda online a una aplicación Android nativa, enfocándose en el diseño visual moderno, la fluidez en la experiencia de usuario y el aprovechamiento de los recursos del dispositivo.

## Características Principales

- **Pantalla principal (Home)**: Navegación fluida e intuitiva entre las diferentes secciones de la aplicación.
- **Formularios inteligentes**: Campos con validaciones visuales y lógicas de negocio desacopladas.
- **Persistencia local**: Almacenamiento estructurado mediante **Room Database** y preferencias de usuario con **DataStore**.
- **Recursos nativos**: Integración directa con la cámara y galería del dispositivo Android.
- **Experiencia visual**: Animaciones fluidas y retroalimentación interactiva constante.

## Objetivo del Proyecto

Explorar el desarrollo de interfaces móviles estructuradas y funcionales, aplicando conceptos avanzados de ingeniería de software móvil:

- Usabilidad y jerarquía visual estricta.
- Gestión reactiva del estado con **ViewModel**.
- Persistencia segura de datos y acceso controlado al hardware del dispositivo.

## Perspectiva Técnica

| Componente / Tecnología | Responsabilidad técnica |
| :--- | :--- |
| **Kotlin / Jetpack Compose** | Interfaz declarativa moderna bajo los lineamientos de *Material 3* |
| **Navigation Compose** | Gestión del enrutamiento y navegación fluida entre pantallas |
| **Room Database** | Capa de base de datos relacional local para persistencia |
| **DataStore & Coil** | Preferencias ligeras de usuario y carga asíncrona optimizada de imágenes |

## Estructura del Proyecto

```text
app/
├─ manifests/
│  └─ AndroidManifest.xml
│
├─ kotlin+java/
│  └─ com/
│     └─ example/
│        └─ bosqueantiguo/
│           ├─ model/ (AppDatabase, Usuario, UsuarioDao)
│           ├─ repository/ (UsuarioRepository)
│           ├─ ui/
│           │  ├─ theme/ (Color, Theme, Type)
│           │  ├─ view/ (AjustesScreen, FormularioScreen, MainScreen, PerfilScreen, ProductoScreen, ResumenScreen)

│
├─ res/ (drawable, mipmap, values, xml)
└─ Gradle Scripts (build.gradle.kts, libs.versions.toml, local.properties, etc.)
```

## Inspiración y Origen

Proyecto basado en la versión web original *Bosque Antiguo*, desarrollada con HTML, CSS y JavaScript, ahora llevada al ecosistema móvil para potenciar la accesibilidad, el rendimiento y la comodidad del usuario en Android.

# Introducción

Esta página web fue desarrollada como una herramienta de apoyo práctico para estudiante de Kinesiología de la **Universidad Andrés Bello (UNAB)** durante su periodo de práctica profesional en el club **Everton de Viña del Mar**.

El proyecto consiste en una interfaz web ligera, accesible y directa, diseñada para visualizar de manera ordenada pautas de movilidad, ejercicios correctivos y recursos audiovisuales (GIFs demostrativos) orientados a la evaluación y recuperación de deportistas. Su objetivo principal es optimizar la guía y el seguimiento kinésico dentro del entorno del club.

## Características Principales

* **Visualización Dinámica**: Integración de recursos en formato GIF para asegurar la correcta ejecución de los ejercicios de movilidad articular y estiramientos.
* **Identidad Institucional**: Inclusión de elementos visuales oficiales (como el escudo de Everton) para mantener un estándar profesional acorde a la institución.
* **Diseño Responsivo y Ligero**: Pensado para ser consultado rápidamente desde dispositivos móviles, tablets o notebooks directamente en el terreno de entrenamiento o consulta clínica.

## Perspectiva Técnica

La aplicación se construyó utilizando tecnologías web esenciales, priorizando un rendimiento rápido y cero dependencias pesadas para asegurar su disponibilidad inmediata en cualquier dispositivo.

| Tecnología / Recurso | Propósito en el proyecto |
| :--- | :--- |
| **HTML5** | Estructura semántica clara para la visualización de contenidos y pautas. |
| **CSS3** | Estilos adaptados con la identidad visual institucional y paleta de colores del club. |
| **JavaScript** | Interactividad básica para la visualización fluida de los recursos y la navegación. |
| **Git & GitHub** | Control de versiones y gestión de código y recursos multimedia. |

* **Accesibilidad Inmediata**: Acceso sin fricciones a pautas de ejercicios mediante interfaces limpias.
* **Impacto Práctico**: Optimización de los tiempos de consulta y demostración de movimientos kinésicos.

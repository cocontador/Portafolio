# Introducción

**WALO** es una plataforma SaaS multitenant diseñada para la digitalización de microemprendedores chilenos. Permite crear una vitrina digital con catálogo de productos, integración de pedidos por WhatsApp y pagos en línea con Khipu, todo optimizado para SEO desde el servidor.

Este proyecto forma parte del **Proyecto de Título** para la carrera de Analista Programador en **Duoc UC, Viña del Mar**.

## Contexto del Proyecto

* **Rubro**: Retail digital — comercio electrónico
* **Segmento**: Microemprendedores y pequeños negocios
* **Modelo**: SaaS multitenant B2B2C
* **Mercado objetivo**: Chile

## Descripción General

WALO permite a cualquier emprendedor tener su tienda online en minutos, sin conocimientos técnicos. Cada tienda obtiene una URL pública (`walo.app/mi-tienda`), un catálogo de productos con imágenes, carrito de compras, integración directa con WhatsApp y pasarela de pago con Khipu. Los dueños de tienda gestionan su negocio mediante un panel de administración completo con métricas de ventas y clics.

## Características Principales

- **Registro y Autenticación**: Sistema seguro de acceso para emprendedores.
- **Vitrina Pública Multitenant**: Cada tienda cuenta con su propia ruta y catálogo personalizado.
- **Pedidos por WhatsApp**: Envío directo de pedidos con un mensaje estructurado y automatizado.
- **Pagos en Línea**: Integración con Khipu respaldada por webhooks de confirmación.
- **Panel de Administración**: Gestión intuitiva de productos, categorías y visualización de planes.
- **Suscripciones**: Sistema de planes escalables (*Inicial, Pro, Business*).
- **Analíticas de Negocio**: Métricas detalladas con filtro por períodos de tiempo.
- **Panel de Moderación**: Herramientas de control para administradores de la plataforma.

## Desarrollo Local y Compras

### Requisitos Previos
- Node.js 20+
- Docker y Docker Compose
- Cuenta en Cloudflare R2 (para almacenamiento de imágenes)

### Configuración inicial
```bash
# 1. Instalar dependencias
npm install

# 2. Copiar variables de entorno
cp .env.example .env
# Completar DATABASE_URL, NEXTAUTH_SECRET, R2_*, KHIPU_*

# 3. Levantar base de datos local
docker compose up -d

# 4. Aplicar migraciones y datos iniciales (seed)
npx prisma migrate dev
npx tsx prisma/seed.ts

# 5. Iniciar servidor de desarrollo
npm run dev
```

### Comandos Útiles
* `npm run dev`: Servidor de desarrollo
* `npm run build`: Build de producción
* `npm run test`: Ejecución de pruebas con Vitest
* `npx prisma studio`: Explorador visual de la base de datos
* `npx prisma migrate dev --name <nombre>`: Crear nueva migración

## Infraestructura y Deployment

La aplicación se ejecuta en un **DigitalOcean Droplet** contenedorizado con **Docker**. La base de datos opera sobre **DigitalOcean Managed PostgreSQL** y los archivos multimedia se alojan de forma segura en **Cloudflare R2**.

Para actualizar el entorno de producción:
```bash
git pull origin dev
docker compose -f docker-compose.prod.yml up -d --build
```
*(Nota: El entrypoint del contenedor ejecuta `prisma migrate deploy` de forma automática al iniciar).*

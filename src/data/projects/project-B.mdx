# Introducción

**Bosque Antiguo (Web App)** es la versión web interactiva de la tienda online, desarrollada utilizando **React** y **Vite** para ofrecer una experiencia de usuario rápida, moderna y altamente receptiva.

Este proyecto sirvió como base estructural y conceptual para entender el flujo de comercio electrónico, el manejo de componentes reutilizables y la navegación dinámica antes de dar el salto al desarrollo móvil nativo.

## Características Principales

- **Entorno de Desarrollo Rápido**: Configurado con **Vite** para aprovechar HMR (*Hot Module Replacement*) y optimizar el rendimiento de compilación.
- **Arquitectura de Componentes**: Interfaces modulares y escalables construidas con **React**.
- **Calidad de Código y Linting**: Configuración estricta con **ESLint** para aplicar buenas prácticas y prevenir errores comunes en el frontend.
- **Diseño Adaptativo**: Estilos cuidados para asegurar una visualización fluida tanto en dispositivos móviles como en pantallas de escritorio.

## Perspectiva Técnica

- **Empaquetado y Build**: Uso de Vite para una gestión eficiente de módulos y optimización de código listo para producción.
- **Gestión del DOM Virtual**: Aprovechamiento de la reactividad de React para renderizar dinámicamente catálogos de productos, carritos y formularios interactivos.
- **Estandarización**: Estructura de carpetas limpia orientada a componentes, enfocada en la gestión de propiedades (*props*) y estados locales.

| Servicio / Herramienta | Responsabilidad |
| :--- | :--- |
| **React** | Biblioteca principal para el desarrollo de interfaces basadas en componentes |
| **Vite** | Entorno de desarrollo y empaquetador ultrarrápido |
| **ESLint** | Análisis estático de código para garantizar consistencia y calidad |
| **HTML / CSS** | Estructura semántica y diseño visual de la tienda |

## Desafíos y Soluciones

- **Optimización del Rendimiento**: Configuración del entorno de Vite y comprensión de sus ventajas de velocidad en comparación con empaquetadores tradicionales.
- **Modularización**: División de la tienda en componentes reutilizables (tarjetas de productos, barras de navegación, formularios) para mejorar la mantenibilidad del código.
- **Consistencia Visual**: Asegurar una transición fluida entre el concepto estético de la marca y su implementación real en el frontend.

> ⚠️ **Lección aprendida**: Establecer patrones de código limpios y una correcta separación de componentes desde el inicio facilitó enormemente escalar la aplicación y adaptar posteriormente su lógica a un ecosistema móvil.

## Resultado

La aplicación web se desplegó con éxito, ofreciendo una plataforma de compras rápida, funcional y escalable.

- **Experiencia de Usuario**: Una interfaz fluida que simplifica la exploración del catálogo y la interacción con la tienda.
- **Colaboración en Equipo**: Desarrollado de forma colaborativa junto a Paulina Zúñiga, César Mongez y Constanza Contador.
- **Evolución Tecnológica**: El éxito de esta versión web inspiró y pavimentó el camino para su contraparte móvil nativa en Android.
